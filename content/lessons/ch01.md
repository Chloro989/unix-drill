# 第1章 場所とファイル

## この章で分かること

コンピュータの中のファイルは、木のような形に整理されています。
根っこが `/`（ルート）で、そこから枝分かれしてディレクトリ（フォルダ）が続き、
葉っぱの位置にファイルがあります。

    /
    ├── home
    │   └── you
    │       └── playground   ← 今あなたがいる場所
    └── usr

シェルを使う人は、この木のどこか一箇所に「立って」います。
その場所を **カレントディレクトリ**（今いるディレクトリ）と呼びます。

コマンドは、特に指定しなければこの「今いる場所」を対象にします。
だから最初に覚えるべきことは、たった 2 つです。

- 今どこにいるか  →  `pwd`
- そこに何があるか →  `ls`

## この章の道具

| コマンド | 意味 | よく使う形 |
|---|---|---|
| `pwd` | 今いる場所を表示 | `pwd` |
| `ls`  | 一覧を表示 | `ls` / `ls -a` / `ls -l` |
| `cd`  | 移動する | `cd 名前` / `cd ..` / `cd` |
| `cat` | 中身をそのまま出す | `cat ファイル` |
| `wc`  | 数える | `wc -l ファイル` |

## つまずきどころ

- `cd` で移動しなくても、`ls 場所` のように**引数で対象を指定できる**ことが多い。
- ピリオドで始まる名前は隠しファイル。`ls -a` で初めて見える。
- `*` はシェルが展開するワイルドカード。正規表現の `*` とは別物（第6章で扱います）。
