# 第2章 中を覗く

## この章で分かること

UNIX の道具は、ほとんどが **「行が縦に並んだテキスト」** を前提に作られています。
1 行が 1 件のデータ。これが共通の約束です。

だから「中を見る」も、行単位で考えます。

- 先頭だけ見たい → `head`
- 末尾だけ見たい → `tail`
- 何行あるか知りたい → `wc -l`
- ゆっくり全部読みたい → `less`

数千行のファイルを `cat` すると、画面を猛烈な勢いで流れ去って何も読めません。
**まず `wc -l` で大きさを測り、`head` で形式を確かめる。** これが作法です。

## この章の道具

| コマンド | 意味 | よく使う形 |
|---|---|---|
| `head` | 先頭 | `head ファイル` / `head -n 20 ファイル` |
| `tail` | 末尾 | `tail -n 5 ファイル` / `tail -f ログ` |
| `wc`   | 数える | `wc -l` 行 / `wc -w` 単語 / `wc -c` バイト |
| `less` | 1 画面ずつ読む | `less ファイル`（**終了は `q`**） |
| `cat`  | そのまま出す | `cat -n` で行番号付き |

## 抜け出せなくなったら

| 状況 | 対処 |
|---|---|
| `less` や `man` で画面が変わった | `q` |
| コマンドが終わらない | `Ctrl+C` |
| 入力待ちのまま戻らない | `Ctrl+D` |

この 3 つを知っているだけで、初心者の詰まりのほとんどは解けます。

## つまずきどころ

- 見出し行のある表で `wc -l` すると、**データ件数より 1 多い**。
- `head -20` は古い書き方。試験では `head -n 20` と書く。
