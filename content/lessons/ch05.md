# 第5章 探す（grep）

## この章で分かること

`grep` は「条件に合う**行**を出す」道具です。単位が行であることが重要で、
1 行に同じ語が 2 回あっても 1 行として数えます。

```bash
grep 探す文字列 ファイル
```

名前は `g/re/p`（global / regular expression / print）という、
昔のエディタの操作の名残です。

## よく使うオプション

| オプション | 意味 |
|---|---|
| `-c` | 該当した**行数**だけを出す |
| `-v` | 条件に合わ**ない**行を出す（除外） |
| `-i` | 大文字小文字を区別しない |
| `-n` | 行番号を付ける |
| `-E` | 拡張正規表現を使う（`|` `+` `?` `{}` がそのまま使える） |
| `-o` | 一致した部分だけを出す |
| `-w` | 単語として一致するものだけ |

まとめて `-vc` のように書けます。

## 同じことをする複数の書き方

```bash
grep -c "ERROR" f
grep "ERROR" f | wc -l     # 同じ結果
```

どちらも正解です。この教材の採点も、実際に実行して結果を比べるので
どちらでも通ります。試験でも同様のはずです。

## つまずきどころ

- 検索が空振りしたら、まず**大文字小文字**を疑う（`-i`）。
- `|`（または）を使うなら `-E` を付ける。付けないなら `\|` と書く。
- パターンは**引用符で囲む**。囲まないとシェルが先に解釈してしまう。
- 見出し行を外すには `grep -v "^見出し語"`。同じことは `tail -n +2` や `sed '1d'` でも。
