# 第6章 正規表現

## この章で分かること

正規表現は「文字列の**形**を書き表す記法」です。
コマンドではなく、`grep`・`sed`・`awk` などに渡して使う共通言語です。

## 記号の一覧

| 記号 | 意味 | 例 |
|---|---|---|
| `^` | 行の先頭 | `^A` … A で始まる |
| `$` | 行の末尾 | `T$` … T で終わる |
| `.` | 任意の 1 文字 | `A.T` … A、何か 1 文字、T |
| `*` | **直前の要素**の 0 回以上 | `AC*T` … ACT, AT, ACCT |
| `+` | 直前の要素の 1 回以上 | `AC+T` … ACT, ACCT（AT は不可） |
| `?` | 直前の要素の 0 回か 1 回 | `AC?T` … ACT, AT |
| `[]` | この中のどれか 1 文字 | `[CG]` … C か G |
| `[^]` | この中**以外**の 1 文字 | `[^CG]` … C でも G でもない |
| `{n}` | ちょうど n 回 | `[0-9]{4}` … 数字 4 桁 |
| `{n,m}` | n 回以上 m 回以下 | `[0-9]{2,4}` |
| `\|` | または | `cat\|dog` |
| `()` | まとまり | `(ab)+` … ab の繰り返し |

`+ ? { } | ( )` は `grep -E` を付けて初めてそのまま使えます。
**迷ったら `-E` を付ける**、と覚えておくと安全です。

## 読み方の手順

長いパターンも、左から順に日本語へ置き換えれば必ず読めます。

    ^A[CG]*[^CG]?T$
     ^A     … A で始まり
     [CG]*  … C か G が 0 個以上続き
     [^CG]? … C でも G でもない文字が 0 個か 1 個あって
     T$     … T で終わる

## 二つの `*` は別物

ここが最大の混乱どころです。

| 場所 | `*` の意味 | 例 |
|---|---|---|
| シェル（ファイル名） | 任意の文字の並び | `ls *.txt` |
| 正規表現 | 直前の要素の 0 回以上 | `grep "AC*T"` |

正規表現で「任意の文字の並び」を書きたければ `.*` です。
`grep` のパターンを引用符で囲むのは、シェルに先に展開されるのを防ぐためでもあります。

## つまずきどころ

- `*` は 0 回を許す。`ID-[0-9]*` は `ID-` にも一致してしまう。1 個以上なら `+`。
- `^` は場所で意味が変わる。行頭の `^` と、`[^…]` の中の否定の `^`。
- 「含む」と「全体が一致する」は違う。全体なら `^` と `$` で挟む。
