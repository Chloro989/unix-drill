# 第7章 並べ替えと集計

## この章で分かること

「何がいくつあるか」を知る型を身につけます。UNIX で最もよく使う一行はこれです。

```bash
sort ファイル | uniq -c | sort -rn | head -n 3
```

    sort      同じものを隣に集める
      ↓
    uniq -c   隣り合う同じ行をまとめて数える
      ↓
    sort -rn  件数で多い順に並べ替える
      ↓
    head      上位だけ取り出す

`sort` が 2 回出てきますが、**役割はまったく違います**。
1 回目は `uniq` のための下ごしらえ、2 回目は件数での並べ替えです。

## この章の道具

| コマンド | 意味 | よく使う形 |
|---|---|---|
| `sort` | 並べ替え | `-n` 数値順 / `-r` 逆順 / `-u` 重複を消す |
| `uniq` | 隣り合う重複をまとめる | `-c` 件数を付ける / `-d` 重複したものだけ |
| `cut`  | 列を取り出す | `-f 2` 2列目 / `-d,` 区切りはカンマ |
| `tr`   | 文字を置き換える | `tr a-z A-Z` / `-d` 削除 |

## 見出し行を落とす三つの書き方

```bash
tail -n +2 file          # 2 行目から最後まで
grep -v "^見出し語" file
sed '1d' file            # 9 章
```

## つまずきどころ

- **`uniq` の前には必ず `sort`。** `uniq` は直前の行としか比べないので、
  離れた場所にある重複は見逃す。エラーは出ず、静かに間違った結果になる。
- `sort` は既定で**文字として**比較する。`9` が `100` より大きいと判定される。
  数値なら `-n` を付ける。
- `cut` はファイル名を引数に取れるが、`tr` は取れない。`tr` はパイプか `<` で流す。
- `cut` は列の順番を入れ替えられない。それがしたければ `awk`（次章）。
