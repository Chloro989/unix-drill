# 第8章 列を扱う（awk）

## この章で分かること

`awk` は「1 行読むごとに、条件を見て、処理をする」小さなプログラミング言語です。
`grep` や `cut` にできない**計算**ができます。

## 基本の形

```bash
awk '条件 { 処理 }' ファイル
```

- 条件を省く → すべての行が対象
- 処理を省く → その行をそのまま出す（`grep` のように使える）

```bash
awk '{print $1}' f            # 全行の 1 列目
awk 'NR>1' f                  # 2 行目以降をそのまま出す
awk '$3 > 100 {print $1}' f   # 条件に合う行の 1 列目
```

## 覚えるべき変数は四つ

| 変数 | 意味 |
|---|---|
| `$1` `$2` … | 1 列目、2 列目 |
| `$0` | 行全体 |
| `NR` | 今何行目か（最後は総行数） |
| `NF` | その行の列数 |

## BEGIN と END

```bash
awk 'NR>1 {s+=$3} END{print s}' f      # 合計
awk 'NR>1 {s+=$3; n++} END{print s/n}' f  # 平均
```

`BEGIN{…}` は読み始める前に 1 回、`END{…}` は読み終わってから 1 回だけ動きます。
変数は宣言不要、初期値は 0 です。

## 区切り文字

```bash
awk -F, '{print $2}' file.csv       # カンマ区切り
awk -F"\t" '{print $2}' file.tsv    # タブ区切り
```

`-F` は `cut` の `-d` に当たります。

## つまずきどころ

- プログラムは**シングルクォート**で囲む。`$1` をシェルに解釈させないため。
- `==` は比較、`=` は代入。`NR=1` と書くと条件が常に真になり全行出てしまう。
- 文字列との比較は `$3 == "ERROR"` のように引用符で囲む。
- 単に探すだけなら `grep` のほうが短く速い。**計算が要るときが `awk` の出番。**
