# 第9章 置き換える（sed）

## この章で分かること

`sed` は「流れてくる行に手を加える」道具です。中心は置換です。

```bash
sed 's/置換前/置換後/'      # 各行の最初の 1 つ
sed 's/置換前/置換後/g'     # 行内のすべて
```

`s` は substitute、`g` は global。
**`g` を付け忘れると 1 行につき 1 つしか置き換わりません。** 定番の落とし穴です。

## 行を選ぶ

| 書き方 | 意味 |
|---|---|
| `sed -n '5p'` | 5 行目だけ印字 |
| `sed -n '1,3p'` | 1〜3 行目 |
| `sed -n '$p'` | 最終行 |
| `sed '1d'` | 1 行目を削除 |
| `sed '/ERROR/d'` | ERROR を含む行を削除 |

`-n` は「自動で出すのをやめる」。`p` と必ず対で使います。
付け忘れると、選んだ行が 2 回出ます。

## 挿入と削除

```bash
sed 's/^/> /'      # 行頭に「> 」を足す（^ は幅ゼロの位置）
sed 's/$/。/'      # 行末に足す
sed 's/ERROR//g'   # 置換後を空にすると削除
```

`d` が**行ごと**消すのに対し、`s///` は**文字列だけ**を消します。

## 元のファイルは変わらない

`sed` は結果を画面に流すだけです。保存したければ `>` で別のファイルへ。

```bash
sed 's/A/B/g' 元.txt > 新.txt
```

`-i` を付けると元のファイルを直接書き換えますが、**取り消せません**。
しかも書き方が環境で違います。

| 環境 | 書き方 |
|---|---|
| Linux (GNU) | `sed -i 's/A/B/' file` |
| macOS (BSD) | `sed -i '' 's/A/B/' file` |

この教材では `-i` を使う問題は出しません。実務でも慎重に。

## つまずきどころ

- プログラムは**シングルクォート**で囲む。`$` をシェルに渡さないため。
- `sed` の中の `$` は「最終行」、正規表現の中の `$` は「行末」。場所で意味が変わる。
- `grep` は行を**選ぶ**、`sed` は行を**変える**。目的で使い分ける。
